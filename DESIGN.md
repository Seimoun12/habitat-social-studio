# Habitat visual direction

## Identity
Habitat is a social studio workspace. It helps a small agency move between client profiles while keeping shared studio work, especially appointments, in one place.

## Audience and mood
For social media managers coordinating several clients across Instagram, Facebook, and TikTok. The interface feels like a contemporary creative studio: composed, tactile, and energetic in a few deliberate moments. It favors useful evidence over promotional language.

## Visual system
- Core colors: forest green `#173ca32`, soft paper `#f6f7f0`, and ink `#17231f`. Acid leaf `#c8ec68` is the single accent, reserved for selected navigation and primary actions.
- `DM Sans` carries dense controls and data legibly. `Playfair Display` gives client and report headings an editorial voice that separates the workspace from generic analytics software.
- The main frame is a compact studio rail beside a fluid work area. Appointments and scheduled content have separate shared destinations, each with independent week and month views, outside the client-specific analytics context.
- Flat white panels organize comparisons. Small radii distinguish bounded work surfaces without turning every control into a pill.
- The chart answers one question: how the selected client's follower count changes over the selected period. The lime accent marks selection and the next action, not every status.
- Interaction uses brief state transitions only. Motion communicates navigation and feedback, not decoration.

## Liveliness dials
ENERGY 2 / RHYTHM 2 / MOTION 1.

## Content and data
All names, numbers, percentages, sample content titles, locations, audience breakdowns, and appointments in the local prototype are fictional demonstration data. Keep the visible `Dati demo` notice. Do not imply connection to social network APIs or present example values as client reporting. The report uses the browser print dialog and can be saved as PDF.
