# Project guidance

Before changing the interface, read `DESIGN.md`, `antislop.md`, and the matching skill under `.github/skills/` (or `.claude/skills/` for Claude Code). Architecture, commands and data rules are in `CLAUDE.md`.

- Interface and visual decisions: `.github/skills/antislop-ui/SKILL.md`
- Accessibility and keyboard behavior: `.github/skills/antislop-human/SKILL.md`
- Responsive layout: `.github/skills/antislop-layoutmobile/SKILL.md`
- Italian product copy: `.github/skills/antislop-copywriting/SKILL.md`
- Client, channel, report, content, appointment and editor behavior: `.github/skills/bynor-social-studio/SKILL.md`

Run `npm run check` and `npm run ui-check` and use the anti-slop Delivery Gate in `antislop.md` before calling UI work complete. Demo data must keep its visible "Dati demo" label.
